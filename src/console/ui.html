GitHub

開 PR、讀審查、合併時用。**agent 拿不到它** —— 執行環境會主動剝掉 GitHub 認證， 所以這個 token 的範圍要涵蓋你打算納管的所有專案，不必為了安全而綁死單一 repo。
權限只需要 Contents (讀寫)、Pull requests (讀寫)、Metadata (讀)。
真正控制「會不會動到你的正式專案」的是每個專案的 PR 目標 repo 與下面的兩個開關。

留空的關卡會被跳過。agent 每一輪跑完後，調度器會**實跑**這些指令， 全綠才算完成——這是它唯一無法自己宣稱通過的關卡。 填了 devServer 才會啟動瀏覽器做視覺驗證與截圖。
單一驗收指令跑多久算逾時。逾時會被判成紅燈，而 agent 收到的訊息是 「測試失敗」——它會開始修一個沒壞的東西。要 migrate 資料庫、跑多語言測試的專案， 全域那個值通常不夠，在這裡覆寫。
